Privacy Policy

MDE Uploader, Midnight Draw Engine. Last updated: November 9, 2026.

What MDE Uploader is

MDE Uploader is a private tool used only by the owner of the Midnight Draw Engine YouTube channel to upload the channel's own Shorts, set their title, description and privacy, and post a comment on the channel's own videos. It is not offered to the public.

Data it accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos to the owner's channel, read and update the status of those videos, and post comments on them. It does not read anyone else's account, viewer data or messages.

How data is stored

The sign-in token that Google issues is stored only on the channel owner's own computer. No data is sent to any other server, sold, or shared with anyone. MDE Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time from their Google Account at myaccount.google.com/permissions, and by deleting the token file from their computer.
